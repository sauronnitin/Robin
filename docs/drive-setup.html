Google Drive (recommended)

Robin can save tailored resumes, cover letters, and PDFs to a Drive folder, and log applications to a Google Sheet. Use a Desktop OAuth client (not a service account). Personal Google accounts give service accounts zero Drive storage quota.

  1. Create or pick a Google Cloud project.
  2. Enable Google Drive API and Google Sheets API.
  3. Credentials → Create credentials → OAuth client ID → Application type: Desktop app.
  4. Download the client JSON into secrets/google-oauth-client.json.
  5. Create a normal Drive folder (not a Drive Project). Copy the folder ID from the URL.
  6. Create a Sheet for your application tracker. Copy the spreadsheet ID from the URL.
  7. In .env:
    GOOGLE_OAUTH_CLIENT_SECRET=./secrets/google-oauth-client.json
    GOOGLE_DRIVE_FOLDER_ID=...
    MASTER_SHEET_ID=...
  8. First run opens a browser login once; the refresh token is cached locally (gitignored).

You can skip Drive and keep outputs local. Scout / tailor still work with DRY_RUN=True.
