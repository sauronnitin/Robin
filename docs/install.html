Install Onboarding Drive

Easiest install

About 10 minutes if you already have Python 3.10+ and API keys.

  1. Optional first: run the web onboarding and download profile.json.
  2. Clone the repo (personal use only, see LICENSE):
    git clone https://github.com/sauronnitin/Robin.git
    cd Robin
  3. Create a virtualenv and install:
    python -m venv .venv
    .venv\Scripts\activate (Windows) or source .venv/bin/activate
    pip install -e .
    playwright install chromium
  4. Copy env template and add keys:
    copy .env.example .env (Windows) or cp .env.example .env
    Set GROQ_API_KEY and GEMINI_API_KEY. Keep DRY_RUN=True.
  5. Drop onboarding output into user/profile.json (and your resume as user/resume.pdf or user/resume.tex). Or start from the example: ROBIN_PROFILE=product-designer.
  6. Start the dashboard:
    python dashboard/server.py
    Open http://localhost:5959
  7. (Recommended) Connect Google Drive using Drive setup, then set sheet + folder IDs in .env.
  8. (Optional) Connect Gmail from Settings after the dashboard is running. The scope is gmail.readonly: the app classifies recruiter replies and cannot send, delete, or modify mail. Reply detection is optional. The Apply board works without it. You just move cards by hand.

Need keys? Groq · Gemini Flash (AI Studio)
