Open-source agent swarm for job hunting

Robin

Answer a few questions about the job you want. Robin builds a local swarm of scout, fit, tailor, cover-letter, and apply agents around your resume. Dry-run by default. Real apply when you are ready.

Start onboarding Install locally

This site is static GitHub Pages. The swarm runs on your machine after install at http://localhost:5959.

1. Choose a role pack

Product Design, Engineering, PM, Data, Marketing, or a custom pack from onboarding.

2. See your swarm

Canvas cards appear from your choices: LinkedIn loop, cover letter, Drive publish, and more.

3. Run dry, then live

DRY_RUN=True until you flip it. Scout and tailor first. Apply when you trust the flow.
