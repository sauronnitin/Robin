Pigments — categorical, opt-in per screen, fixed order, never cycled

A screen earns pigments only when it carries genuinely categorical series that are not already distinguished by a direct label. If the marks are labelled, hue encodes nothing the text does not, and spending it costs the monochrome read — use the wash steps instead. The Dashboard runs on ink and rubric alone: one chromatic value in either mode.

05

Elevation & Depth

There are no drop shadows in this system. Depth comes from three warm surface steps separated by hairlines — layering is how physical paper actually stacks, and a shadow would simulate a lighting model paper on a desk does not have.

paperPage ground. Everything sits on it.
leafCards, bands, chart surfaces. One step up.
raisedInputs, inset panels, table headers.
2px ink ruleFor a stronger division — never a heavier shadow.

Card anatomy — five slots, fixed order

Only the label is required. The rest are optional but never reorder. One figure per card — a second number means a second card, or prose in the subline. The viz sits on the card floor at full width (margin-top:auto), so every plot in a row lands on the same line. A plot tucked beside the figure makes two focal points inside one small card, and the figure loses.

1 · label
64%2 · unit, on the baseline

3 · subline — the plain-English reading of the figure.

4 · viz bandon the floor
5 · caption — the citation or the caveat

A single ratio is a meter, never a two-slice ring — the number is already printed larger beside it, so a donut restates and competes with it. Rings are for part-to-whole with three or more segments, and even then a stacked split usually reads better at card width.

07

Do's and Don'ts

✓ Do

  • ✓Keep exactly one loud thing per view. If two elements are red, neither is.
  • ✓Carry state with an icon, a label, and a weight — colour is the last channel, never the only one.
  • ✓Set every figure in a tabular numeral style so columns align.
  • ✓Use hairlines and surface steps for structure; let layering do what shadows would.
  • ✓Re-run the palette validator before introducing any colour.
  • ✓Keep ochre in illustration and rubric in interface — they measure 1.47:1 against each other.

✗ Don't

  • ✗Don't add a success green or a congratulatory state. Nothing here congratulates.
  • ✗Don't use red for staleness, waiting, or lateness. Silence gets neutral ink.
  • ✗Don't introduce a sans-serif. The serif/mono pairing is the identity.
  • ✗Don't add drop shadows, gradients, or radii above 8px.
  • ✗Don't cycle categorical pigments for a seventh series — fold it into "Other".
  • ✗Don't let text wear a pigment colour. The mark carries identity; the number stays in ink.
