# O*NET data bundle

Derived from the O*NET 30.x Database, developed by the U.S. Department of Labor,
Employment and Training Administration (USDOL/ETA). O*NET is public domain;
this product is not endorsed or sponsored by O*NET or USDOL/ETA.

- `occupations.json` — generated by `scripts/build_onet_bundle.py` from the O*NET
  bulk text-file database. Re-run that script after downloading a newer O*NET
  release to refresh this file.
- `ai_exposure.json` — hand-curated coarse estimate, not sourced from O*NET.
  Informational only.
- `riasec_items.json` — original quiz items (see Task E), not O*NET's
  copyrighted Interest Profiler text.
